[ 생성자 ]
    1) 인스턴스(객체) 생성할 때 초기화 담당
        new 생성자명 ()
    2) 사용법
        1. 클래스 내부 선언
        2. 클래스명 동일
        3. 반환타입 없다
        4. 오버로딩 지원( 동일한 이름의 서로 다른 매개변수의 개수/타입/순서 다르면 중복가능 )
    3) 목적 : 객체생성시 초기화 , 협업간의 규칙/유효성검사
    4) 주의할점 : 정의한 클래스내 생성자가 1개도 없으면 기본생성자 (자동) 제공
    5) this 키워드 : 맴버변수와 매개변수 명이 동일한 경우 맴버변수 가리킴.
    * 클래스내부에서 오른쪽클릭 -> 소스작업 -> constructor -> 맴버변수 체크 -> [확인]*
